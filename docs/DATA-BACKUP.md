# Data pengguna

Source, konfigurasi build, dan referensi ZIP tersedia di repository. Inventori, resep, riwayat, akun lokal, dan draft pada browser pengguna belum dicadangkan oleh AI.

Pemindahan kode tidak memindahkan data tersebut. Sebelum memakai domain/browser baru, lakukan migrasi data dapur secara terpisah, tanpa membawa kata sandi atau sesi lokal. Periksa jumlah produk, batch, resep, aktivitas, kategori, lokasi, dan master item setelah import.

Jangan memasukkan backup localStorage pribadi ke GitHub atau konteks AI. Pengembangan lokal menggunakan akun uji baru melalui tab Daftar.
