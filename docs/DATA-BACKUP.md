# Kode dan data pengguna

Paket project ini hanya membawa aplikasi dan dokumentasi. Inventori, resep, riwayat, serta akun yang tersimpan di browser pengguna belum diambil atau dicadangkan oleh AI.

## Sebelum memindahkan penggunaan ke domain/browser lain

1. Pastikan project dapat dijalankan dengan akun uji baru.
2. Periksa fasilitas backup pada aplikasi yang benar-benar tersedia. Jangan menganggap export source juga mengekspor inventori.
3. Jika belum ada export data, rancang alat migrasi terpisah yang mengekspor data dapur saja, tidak membawa kata sandi atau sesi lokal.
4. Verifikasi jumlah produk, batch, resep, aktivitas, kategori, lokasi, dan master item setelah import pada origin baru.
5. Simpan backup pribadi di luar GitHub dan jangan menempel data akun/kata sandi ke chat AI.

Memindahkan project ke GitHub tidak memerlukan pemindahan data browser sekarang. Website yang lama dan data browsernya tidak disentuh dalam proses pengarsipan kode ini.
